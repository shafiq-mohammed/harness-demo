# T-001: App skeleton and health check

Status: todo
Depends on: none

## Goal
The service starts from an app factory with injected settings and clock, answers `GET /healthz`, and turns every client error into a JSON error envelope.

## Scope
In:
- `create_app(settings, clock)` factory storing both on `app.state`; module-level `app = create_app()`.
- `Settings` with `api_keys` and `Settings.from_env()` reading `LINKS_API_KEYS`.
- `Clock` protocol, `SystemClock`, `FixedClock`.
- `ApiError` and `register_error_handlers` producing the error envelope for 404 / 405 / 422.
- `GET /healthz`.
- `tests/conftest.py` with `T0`, `clock` and `client` fixtures (no `repo` yet).
Out:
- API key auth, `Link` model, repository, `POST /links` - T-002.
- Redirecting - T-003. Expiry - T-004. Listing - T-005.
- Dockerfile, persistent storage.

## Interface (copied from docs/SPEC.md so the ticket is self-contained)
- Modules: src/app/settings.py, src/app/clock.py, src/app/errors.py, src/app/routes/__init__.py,
  src/app/routes/health.py, src/app/main.py

```python
# src/app/settings.py
@dataclass(frozen=True)
class Settings:
    api_keys: frozenset[str] = field(default_factory=frozenset)
    @classmethod
    def from_env(cls) -> "Settings": ...
    # Reads LINKS_API_KEYS (comma-separated, whitespace stripped, empty entries dropped).
    # Unset or empty variable -> empty frozenset.

# src/app/clock.py
class Clock(Protocol):
    def now(self) -> datetime: ...          # always tz-aware UTC
class SystemClock:
    def now(self) -> datetime: ...          # datetime.now(UTC)
class FixedClock:
    def __init__(self, now: datetime) -> None: ...   # raises ValueError if naive
    def now(self) -> datetime: ...
    def set(self, now: datetime) -> None: ...        # raises ValueError if naive
    def advance(self, seconds: float) -> None: ...

# src/app/errors.py
class ApiError(Exception):
    def __init__(self, status_code: int, error: str, message: str) -> None: ...
def register_error_handlers(app: FastAPI) -> None: ...
    # ApiError -> its status + envelope.
    # Starlette HTTPException 404 -> 'not_found', 405 -> 'method_not_allowed'.
    # RequestValidationError -> 422 'validation_error' with "details".

# src/app/main.py
def create_app(settings: Settings | None = None, clock: Clock | None = None) -> FastAPI: ...
    # defaults: Settings.from_env(), SystemClock(). Stores app.state.settings, app.state.clock.
    # T-002 adds a `repo` parameter between settings and clock; callers use keyword arguments.
app = create_app()
```

- Error envelope for every 4xx (`Content-Type: application/json`):
  `{"error": "<snake_case_code>", "message": "<human readable>"}`; `validation_error` adds a
  `"details": [{"loc": [...], "msg": "..."}]` list.
  Codes in this ticket: `not_found` 404, `method_not_allowed` 405, `validation_error` 422.
- `GET /healthz` -> 200 `{"status": "ok"}`. No auth, no headers required.

## Acceptance criteria
AC1. Given the app is built with `create_app(settings=Settings(), clock=FixedClock(T0))` When `GET /healthz` is requested with no headers Then the response is 200 with JSON body exactly `{"status": "ok"}`.
AC2. Given the app When `GET /no-such-route` is requested Then the response is 404, `Content-Type` is `application/json`, and the body is `{"error": "not_found", "message": <non-empty string>}`.
AC3. Given the app When `POST /healthz` is requested Then the response is 405 with body `{"error": "method_not_allowed", "message": <non-empty string>}`.
AC4. Given the environment variable `LINKS_API_KEYS` is set to `" a, b ,,c "` When `Settings.from_env()` is called Then `api_keys == frozenset({"a", "b", "c"})`; and when the variable is unset Then `api_keys` is an empty frozenset.
AC5. Given `FixedClock(T0)` When `advance(60)` is called Then `now()` returns T0 + 60 seconds; and constructing `FixedClock` with a naive datetime raises `ValueError`.
